# FreshMart Nigeria PLC | Executive Profit & Cost Analysis (2024–2025)

## Project Overview

An end-to-end Business Intelligence project developed using **Microsoft Excel** , **SQL** and **Microsoft Power BI** to analyse FreshMart Nigeria PLC's financial and operational performance. The project involved building two interactive executive dashboards to monitor costs, evaluate profitability, and support data-driven business decisions.

## Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- Data Modelling (Star Schema)

## Project Tasks

### 1. Data Modelling
- Imported and transformed the dataset.
- Designed a Star Schema data model.
- Established appropriate table relationships and cardinality.

### 2. DAX Measures
Developed 10+ DAX measures, including:
- Total Sales
- Total Cost
- Total Profit
- Profit Margin
- Total Transactions
- Total Quantity Sold
- Average Order Value
- Total Customers
- Sales per Store
- Sales per Category

### 3. Executive Dashboards

**Cost Analysis Dashboard**
- Analysed costs by store, product, category, and region.
- Identified major cost drivers.
- Monitored cost trends over time.

**Profit Analysis Dashboard**
- Analysed profitability by store, membership, and category.
- Evaluated regional contributions.
- Monitored yearly profit trends.

![FreshMart Profit Dashboard](https://github.com/Oladotun123/Freshmart-business-intelligence-analysis/commit/9c8e4ce8cfb14f0ef52018a729d8929fb4be4f06)

### 4. Business Insights & Recommendations
- Developed 10 business insights from the analysis.
- Provided 5 strategic recommendations to improve cost efficiency and profitability.
- Prepared a five-minute executive presentation.

| KPI | Result |
|---|---:|

| Total Profit | ₦126M |
